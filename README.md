# inkstand

inkstand is a toolkit for interactive terminal applications built with
[Ink](https://github.com/vadimdemedes/ink). It contains useful components like a command
line editor, a command router or screen handling.

## Quick start

inkstand needs Node 22 or later, Ink 7.1, and React 19. `ink` and `react` are peer
dependencies, so install them together:

```sh
npm install inkstand ink react
```

Follow up with the [Tutorial](docs/guide/01-bootstrap.md) that builds an application step
by step.
